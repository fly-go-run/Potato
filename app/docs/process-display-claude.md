# 过程展示重构设计（Claude 独立稿）

对象：会话里"任务是怎么被解决的"这条叙事线。参照 Codex 客户端
（手机端实拍 + 既有认知），先诊断差距，再给方案。

## 0. 先承认已有的底子

turnTimeline/TurnFlow 这层已经是 Codex 式骨架：叙述恒留正文流、
append-only 槽位、渐进收口、失败恒可见、产物突出卡、行尾时长心跳、
FileChangesCard 收口卡。**骨架不是差距，静息态的信息密度才是。**

## 1. 差距诊断（对照用户截图）

| Codex | Potato 现状 | 判断 |
|---|---|---|
| 头是「Worked for 1m 43s」——时间 | 「已完成 4 个步骤」——计数 | 计数无信息（和「会话(46)」同病）：说了做了几件事，没说做了什么。词汇还是系统概念（步骤） |
| 步骤摘要行平铺在正文流里：「Searched web 3 times for site:help.openai.co…」，带对象、带聚合次数，每行可展开 | 全部过程藏在一个 chevron 后面，展开就是原始工具行全量 | **缺中间层**。Codex 是三个海拔：头 / 摘要行 / 原始详情。我们只有两个：头 / 全量，静息态什么都看不见，展开又全都来 |
| 开工先说一句计划（「我先按…来规划…」） | 叙述通道已支持，但模型很少开口 | 前端已就绪，缺后端提示词引导 |
| 重要步骤露出（关键检索、编辑），常规步骤收进计数 | 失败/产物已恒可见，其余一律折叠 | 方向对，粒度不够 |
| 过渡动画 | 280ms struct 收口已有 | 非差距 |

一句话：**Codex 的静息态讲故事，我们的静息态报数。**

## 2. 方案：给执行轨道加"摘要行"海拔

### 2.1 头部改词

- 进行中：保持现状（当前工具名/思考中 + `· 12s` 心跳）——这部分
  已经对。
- 收口后：`工作了 1 分 43 秒`（en `Worked for 1m 43s`）。时长即
  头衔，步骤计数死掉。无计时的历史会话回落为「查看过程」。
- 失败仍带失败态文案。

### 2.2 摘要行（新的中间海拔）

把每段 run（连续的工具/思考条目）由"整段隐藏"改为"压成摘要行,
恒可见"。聚合规则：**连续同类合并**，行 = 动词 + 对象 + 聚合数：

- 检索：`检索网页 ×3 · deepseek harness 架构`（对象取首次 query，
  截断）
- 读文件：`读取 5 个文件 · ChatView.tsx 等`
- 改文件：`修改 2 个文件 +38 −12`（与行内彩色 ± 一致）
- 命令：`执行 4 条命令 · npm test 等`
- 思考：`思考 · 18s`
- 其他技能：人话名（走 skillPresentation）+ 次数

每行行首 14px 语义图标（与工具行同形），行尾 chevron；点击展开
该组的原始条目（现 TrackEntry 渲染，能力不变）。原始层默认收拢。

退化路径：run 里只有一个条目时，摘要行就是现有的单工具行本身
（不套两层）。纯文本回答无头无行，现状保持。

### 2.3 静息态 = 头 + 摘要行

流式中：活跃段展开原始行（现状不变，实时感来自这里）；被接替的
段落收拢成摘要行而不是消失。收口后：正文流里留下的是
`叙述 → 摘要行 → 叙述 → 产物卡 → 答案`——不点任何东西就能读出
解决路径。整体折叠开关保留在头上（超长轨道一键全收，回到纯答案）。

### 2.4 详略规则（沿用并明确）

恒可见：失败条目、交付产物卡、FileChangesCard、叙述。
摘要行海拔：常规工具组、思考。
原始海拔：单条工具的入参出参（现 ToolDisclosure）。
密度切换(summary/detailed)继续管原始海拔的行内详略。

## 3. 需要后端/提示词的部分（无硬依赖）

1. **计划先行叙述**：系统提示词加一条「开工前用一句话说明打算怎么
   做，阶段转换时一句话过渡」。纯 prompt 改动，前端 narration 通道
   现成。没有它方案照常成立，有它故事完整。
2. 检索 query、命令文本、文件路径均已在 arguments/qp meta 里，
   摘要行聚合纯前端。
3. 计时已有（getMessageTiming），无新增事件。

## 4. 分阶段

- P1（纯前端，小）：头部改词（时长化）；run 收拢目标从"隐藏"改为
  "摘要行"。turnTimeline 不动，只改 TurnFlow 的物化层 + 一个聚合
  reducer（~150 行）。
- P2：摘要行逐组展开、对象截断细节、动效打磨（280ms 沿用）。
- P3（后端）：计划先行提示词；观察真实会话再调聚合阈值。

风险：摘要行让长轨道的静息态变高（原来一行，现在 N 行）。约束：
摘要行数上限 ~8，超出合并为「另有 N 步 ›」尾行——详略得当的
"略"字不能丢。
