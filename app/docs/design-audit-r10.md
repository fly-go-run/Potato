# 设计深审 r10 —— 设置以外的全部界面(2026-08-03)

方法:Claude 浏览器实测走查(技能/记忆/定时任务/收件箱/聊天/侧栏)+ codex(gpt-5.6-sol high)独立代码层产品审查,双方发现合并。设置窗口(r9 已重做)不在本轮。codex 报告原文见 `product-review-r10-brief.md` 派发的输出;本文为合并去重后的执行版,行号引用以 codex 报告为准。

## 最伤的前 5(合并双方判断)

1. **收件箱是后端日志查看器**(实测坐实):8 条未读全是「AutoDream completed - Date… Files: 0 scanned, 0 changed…」英文日志裸转发,零结果的例行运行也逐条推送。收件箱作为"任务结果"页完全失效,badge 数字全是噪音。
2. **定时任务投递目标裸 ID + 默认选中**(codex P0):新任务默认选第一条 `channel · user_id · session_id`,存在真实误投风险。
3. **审批卡「批准同类」无范围确认**(codex P0):一键扩大授权,范围只藏在 hover title 里。
4. **加载失败伪装成空态**(四页通病):接口失败时同时渲染错误条和"还没有技能/记忆/任务/消息",把故障解释成没数据,甚至诱导重复创建。
5. **「重新生成」语义不成立**:实际是把上一条问题当新消息重发,不是重新生成。

## 按页面(P0/P1 摘要;P2 见 codex 原文)

### 收件箱(最重灾)
- 【P0】条目正文 = 后端任务日志原文(英文、计数字段堆砌)。需要 presentation model:标题=任务名,正文=一句人话结论("本次整理没有新内容"/"整理了 2 个文件");零结果运行聚合或默认折叠,不计未读。(实测)
- 【P1】运行轨迹直接显示 trace.status / 原始 JSON;应转成"开始执行/调用某能力/已投递/失败"时间线。(codex)
- 【P1】`source_id/run_id` 未转成「打开原任务/打开结果会话」跳转,收到结果回不到上下文。(codex)
- 【P1】轨迹加载失败 = 空框,错误飘在页顶。(codex)

### 定时任务
- 【P0】投递目标默认选中 + 裸 ID 展示(见 top5-2)。
- 【P1】无目标时只说"请先创建会话",无入口、表单不暂存;状态接口失败被映射成"已启用";保存成功无反馈;运行记录错误原文直塞。(codex ×4)

### 聊天页 / Composer / 消息卡
- 【P0】审批卡「批准同类」需确认层展示范围。(codex)
- 【P1】「重新生成」语义(top5-5);限流 banner 只切模型不重试;审批档位入口永远显示"默认权限"且四档无解释;技能列表加载失败后 `/` 永久空;@ 文件同名互覆且无来源;上下文用量只在首页托盘渲染、会话里反而看不到;ProgressCard 生产环境失败不可见 + 后端字段直出。(codex ×7)
- 【P2】助手署名 APP_NAME 与 Potato 品牌两层混用;会话内搜索首次 Enter 跳第二条。(codex)

### 技能与插件
- 【P1】技能描述 = 给模型看的英文触发 prompt 原文("Use this skill when…")直接展示给用户;需要面向人的中文一句话描述(presentation model 或后端补 display_description)。(实测,codex 漏)
- 【P1】技能池导入静默装进第一个工作区;Hub 取消安装无终态反馈。(codex)
- 【P2】页面图标统一灰色方块,与设置内联列表的 emoji 不一致;插件来源徽标裸 URL/路径。(实测+codex)

### 记忆
- 【P1】编辑抽屉 Esc/遮罩/取消直接丢弃草稿,无脏确认。(codex)
- 【P2】详情读取失败无重试;条目标题为 agent 生成的英文(引导后端生成中文标题,前端不强改)。(codex+实测)

### 侧栏 / ⌘K / 收起态
- 【P1】改名/删除/置顶失败静默(错误只写进聊天 store,在其他页面不可见);⌘K 里的"打开设置"没带 background(与其他入口行为分裂,会变整页)。(codex)
- 【P2】收起态丢失未读徽标与搜索入口;"搜索会话"实为命令面板,命名不符。(codex)

### 全局
- 【P1】loading / load-error / loaded-empty 三态互斥(四页统一修);错误 presentation model 统一(HTTP/业务码 → "发生了什么+下一步",原文进技术详情)。(codex)
