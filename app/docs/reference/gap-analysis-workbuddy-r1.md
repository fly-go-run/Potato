# WorkBuddy 对标差距分析 r1

- 日期:2026-07-28
- 参照物:WorkBuddy v5.3.5(Electron),32 张采集图在 `.reference-shots/workbuddy/`,采集日志 `capture-log.md`
- 对比对象:QwenPaw 前端 r5(未 commit)
- 范围:QwenPaw 只做办公模式,三模式 tab、营销/积分/活动卡、吉祥物、多模型倍率 UI 均**不在对标范围**

## 0. 总判断

架构无差距(两者都是 web 技术;我们走 Tauri 反而更轻)。差距集中在四处:**首页空态的产品感、composer 的双层结构、会话页消息动作行/产物呈现、侧栏信息层次**。WorkBuddy 的精致感来源可以概括为:大留白 + 极轻表面差(相邻表面只差 3-8 个灰阶)+ 全部弹层挂靠 composer + 黑色主按钮做唯一视觉锚点。这些全部可以在现有 React + tokens 体系内实现。

## 1. 色板与表面体系(截图实测采样)

浅色:

| 表面 | WorkBuddy | 说明 |
|---|---|---|
| 主区背景 | `#FAFAFA` | 不是纯白 |
| 侧栏背景 | `#F2F2F2` | 比主区深一档 |
| 侧栏选中条 | `#E6E6E6` | 圆角满宽条,无 accent 色 |
| composer 输入卡 | `#FFFFFF` | 全页最亮表面=视觉中心 |
| composer 底栏 | `#F4F4F4` | 与输入卡连成一体,承载工作空间/权限 chip |
| 产物文件卡 | `#F2F2F2` | 无描边,靠底色区分 |
| 用户附件气泡 | `#ECECEC` | 用户消息不用 accent 底 |

深色(注意:**层级方向反转,用抬升表达**):

| 表面 | WorkBuddy |
|---|---|
| 主区背景 | `#141414` |
| 侧栏/composer 输入卡 | `#1F1F1F`(比主区亮) |
| composer 底栏 | `#292929` |
| 侧栏选中条 | `#3A3A3A` |

要点:主按钮统一近黑(深色下近白);绿色只做品牌/连接状态点缀;整页几乎无阴影,弹层才有明确投影。

QwenPaw 现状:tokens 体系(r2-r4)方向一致(中性化侧栏、压深 accent),但表面差更平——我们侧栏/主区/卡片的灰阶对比不如 WB 清晰,深色模式没有"抬升"语义。

## 2. 逐区差距

### 2.1 首页空态(差距最大)

WB:品牌大标题 →模式 tab → 能力 chips 一排(圆角胶囊、icon+文字、可横向滚动)→ 大 composer(约两行高)→ 下挂工作空间/权限底栏。整页内容垂直居中偏上,产品感强。
QP r5:问候语 + composer + 建议卡。骨架相似但:无品牌锚点、无能力入口、composer 单层单行、视觉密度低显得"空"。

可借鉴(办公模式聚焦版):
- 标题区给品牌名+一句话(不需要吉祥物,可用 logo 字标)。
- **能力 chips 映射到我们的技能系统**:点击 chip → 经 composerDraft 机制预填提示词(机制已有,r5 建议卡就是这么做的,升级为 chips 形态 + 图标)。
- composer 初始高度提到两行,发送键改圆形实心。

### 2.2 Composer(结构性差距)

WB 是"三明治"结构:上层白色输入卡(placeholder 内嵌 @ 和 / 的提示)+ 内行工具(+ 菜单 | 模型选择 | 语音 | 圆形发送)+ 下挂浅灰底栏(工作空间 chip、默认权限 chip)。所有弹层(+ 菜单、模型、工作空间、权限、@ 引用、/ 技能)都紧贴 composer 展开,`/` 的技能列表和 composer 连成一个视觉整体(见 16 图)。
QP r5:单卡片,chips 内嵌一行(附件/项目/模型/审批),自动增高 1-8 行已做。

可借鉴:
- 双层结构:项目 chip + 审批档位移到下挂底栏(它们是"会话环境",和"本次输入"分层是对的信息架构)。
- `/` 触发技能列表弹层(功能补齐:后端技能已有,composer 只差触发器;样式照 16 图,列表项=技能名+一行描述)。
- `@` 触发引用会话文件(我们有附件体系,@ 列出当前会话文件,空态文案照 15 图)。
- placeholder 学 WB:"今天帮你做些什么?@ 引用对话文件,/ 调用技能与指令"这种把快捷方式教给用户的写法。

### 2.3 会话页

WB(10/31 图):
- AI 消息尾部有**动作行**:复制/点赞/点踩/朗读/重新生成/分享/更多,右侧显示消耗和模型档位;小图标、低对比、hover 才显色。
- "已完成 1m14s >"折叠行(执行过程收纳,同我们的工具卡收纳思路)。
- **产物文件卡**:icon+文件名+大小+右上角打开按钮,满宽浅灰底,下面跟"查看所有产物 (1) >"入口(右侧有产物面板,顶栏可切)。
- 用户附件消息:文件 chip+文字在浅灰气泡内右对齐。
- 底部"内容由 AI 生成,请核实重要信息"极浅提示。

QP r5:工具卡完成态已改安静行,正文当主角——方向对。缺:消息动作行(至少复制/重新生成)、产物文件卡的规格感(大小/打开按钮/统一底色)、会话级产物汇总入口。

### 2.4 侧栏

WB(220px):顶部窗控+折叠/搜索/筛选图标行 → 品牌名+版本号 → 固定功能区 → **"任务 (5)" 分组标题(计数+折叠 chevron)**,条目=标题+右对齐相对时间 → "空间 (1)" 分组 → 底部账号栏(头像+用户名+通知铃+反馈)。收起态(09 图):侧栏消失,左上只留一排紧凑图标,内容区满宽。
QP r5:功能入口+会话列表,r4 已中性化。缺:分组标题带计数/折叠、会话条目相对时间、底部账号/设置锚点区、收起态。

### 2.5 定时任务页(意外收获)

WB 自动化页(07 图):左上"定时任务/运行记录"分段控件 → 居中空态+黑色主按钮 → 下半区**模板卡网格**(3 列,icon+标题+一行描述:每日新闻推送、每周工作周报、会议前准备…)。
QP:定时任务页只有空态卡。模板卡是低成本高感知的改进:预置办公向 cron 模板(每周周报、会议准备、每日摘要),点击→预填新建表单。"运行记录" tab 我们有收件箱承载,可先不动。

### 2.6 设置与全局

- WB 设置是**居中模态**(19 图):左侧 11 分区导航+右侧分组卡,含字号滑杆、存储用量条。QP 是整页路由。模态更符合桌面 app 心智,但改动大,优先级放低。
- 快捷键页(27 图):表格+keycap 徽章+可清除绑定。QP 的 ⌘/ 速查是只读的,够用,暂不对标可编辑绑定。
- 全局搜索(17 图):居中弹层,默认展示最近任务+日期。QP ⌘K 三分区面板已更强,不动。
- 账号菜单(18 图):浅色/深色切换放一级菜单——QP 主题切换在设置里,可考虑加到侧栏底部账号区,一步可达。

### 2.7 深色模式

WB 用"抬升"层级(见 §1),整体近黑但侧栏/composer 微亮,绿色状态点保留。QP 深色是同方向压暗。若采纳"抬升"语义,只需改 tokens 的深色表面组,一处生效。

## 3. 明确不抄

三模式 tab、营销活动卡/积分/推广、吉祥物、语音输入、多模型倍率与 Max 模式 UI、可编辑快捷键绑定、助理/专家/连接器页(与 QwenPaw 产品定位无关)。
