## 已采集事实(Skills 页,关联 01-skills.png)

### 窗口与侧栏

- 侧栏极浅灰底,与主区白底之间**无可见分隔线**,靠色差(极弱)+ 内容留白区分
- 侧栏结构自上而下:标题行(`Codex ∨` 下拉 + 右侧搜索图标)→ 主导航(New chat / Pull requests / Sites / Scheduled / Plugins,线性图标 + 文字)→ `Projects` 分组(小号灰字组标题,文件夹图标 + 项目名列表)→ `Recents` 分组(**纯文字行,无图标**)→ 底部用户身份行(头像 + 用户名 + 帮助图标)
- 选中态(Plugins):**中性灰药丸填充,墨色文字**,无 accent 色
- Recents 会话行:纯文本,超长省略;其中一行右侧有一个小的音频/活动指示图标

### 主内容区

- 顶部工具行:左侧 `Plugins | Skills` 两个 chip 式页签(当前页签白底描边浮起),右上:刷新图标 + 齿轮图标 + `Create ∨` **深色近黑主按钮**
- 页头:超大标题 `Skills`(约 34-38px)+ 次级说明文字,居中列约 860pt 宽
- 搜索框:**通栏全宽**,圆角矩形(非全圆),放大镜前缀,置于页头与内容之间
- `Installed` 小节:节标题 + 下方 hairline 通栏分隔线
- 技能列表:**两列网格**,无外框卡片、无行分隔线,行间距大(约 24pt)
  - 每行:图标块(约 40pt,圆角,**保留彩色**——多数是同一个彩色立方体默认图标,个别有专属彩色图标)+ 名称(半粗)+ 单行截断描述(灰)
  - 行尾:**一枚安静的灰色对勾**表示已启用——没有开关列(启用/停用交互收进别处)
- 列表底部:`See Meishi Auth, Meishi Calendar, and 21 more` 文字式展开器(灰色,非按钮样式)
- 分类页签:`Personal | System | Recommended` 文字 chip,选中项灰底药丸,其后再接同构的两列网格
- 整页除彩色技能图标外**零 accent 色**:主按钮近黑、选中态灰、对勾灰
