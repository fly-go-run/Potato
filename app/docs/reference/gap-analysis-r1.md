# 差距分析 R1:QwenPaw vs Codex 桌面 app

依据:`.reference-shots/codex-app/`(50 张参照截图 + capture-log.md)、`qwenpaw-verify-report.md`(codex 逐项操作验证)、QwenPaw r4 现状截图。
分析人:Claude(审美/交互判断);事实采集:Claude 子智能体(键盘导航)+ codex(computer use 验证)。

## 一、会话视图(核心面,差距最大)

### 1. 工具活动的视觉权重 【高杠杆】
- **参照**:执行过程折叠为安静的 `Worked for 39m 46s ›` 纯文本行 + hairline,"Searched the web" 同构;AI 正文是版面唯一主角。工具明细默认全部隐藏。
- **现状**:每条 shell 命令一张灰底通栏大条卡,多命令会话里工具卡数量压过正文,版面呈"卡片流"而非"文档流"。
- **改进**:连续完成态工具调用聚合为一行安静折叠行(如"已执行 5 个命令 · 12s ›"),展开见逐条明细;运行中/待审批的保持展开态突出。审批卡不动。

### 2. 流式跟随与"回到底部" 【高杠杆】
- **参照**:自动跟随生成;用户上滑即停,出现"回到底部"pill,点击恢复跟随(他们 iOS 版把"不持续跟随"列为 P0 修复,可见其权重)。
- **现状**:跟随行为未经验证,无"回到底部"控件。
- **改进**:流式时锚定底部;上滑打断;悬浮"回到底部"按钮(含新内容暗示)。

### 3. 文件编辑聚合卡 【候选,依赖后端事件形态】
- **参照**:`Edited 13 files +2,178 −287` 卡:头行(图标+标题+增删统计+Undo/Review),逐文件行(灰路径+粗文件名+右对齐 ±N),`Show 10 more files` 展开器。白底描边卡,无填充。
- **现状**:文件编辑散落为独立工具卡。

### 4. 会话列宽
- 参照约 870pt,我们 768(max-w-3xl)。可考虑 chat 单独放宽一档,低优先。

## 二、新会话空态

### 5. 建议任务卡 【可选】
- **参照**:居中 hero("What should we build?")+ 4 张白底描边建议卡(淡彩小图标 + 两行文案),composer 沉底并挂 "Choose project" 栏。
- **现状**:r4 已改为 hero + composer 居中直连(更接近 ChatGPT 式)。布局不折腾;可选补"办公任务建议卡"(如 整理收件箱/写周报/处理表格),空态更有引导性。

## 三、全局交互

### 6. ⌘K 升级为命令面板 【桌面级标配】
- **参照**:⌘K 全能面板:搜索会话+项目 chip 过滤+⌘1-9 快速打开+(深色版还有 Search files ⌘P)。有键盘选中态与 hover 态之分。
- **现状**:⌘K 是纯会话搜索 dialog。
- **改进**:升级为命令面板:页面导航(定时任务/收件箱/技能/记忆/设置)+ 会话搜索 + 常用动作(新建会话/切主题),数字键快开。

### 7. ⌘/ 快捷键速查模态 【低成本高质感】
- **参照**:⌘/ 唤出全量快捷键分组模态(Chat/Navigation/Panels/Project/App/General),菜单栏同步露出快捷键。
- **现状**:有基础快捷键,无速查界面。

### 8. Accent 校准 【token 微调】
- **参照**:浅色 accent `#0169CC`(深而稳的蓝),前景 `#0D0D0D`,对比度档位 45;深色用 GitHub 预设(accent `#1F6FEB`,bg `#0D1117`)。
- **现状**:我们浅色 accent `#3b6ef0` 偏亮偏紫。可压向更深更稳(如 `#2563eb→#1f5fd6` 一带实测定)。深色 bg 我们中性 `#0f0f12`,他们偏蓝——**保持中性,不跟**。

### 9. 侧栏会话行 hover 预览 【锦上添花】
- **参照**:hover 会话行浮出右侧小卡(标题+时间+类型 chip),行尾浮现置顶等快捷图标。
