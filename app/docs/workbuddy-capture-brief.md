# 任务:用 computer use 采集 WorkBuddy 桌面 app 参照截图

你的任务是操作本机已安装的 WorkBuddy(`/Applications/WorkBuddy.app`,v5.3.5,Electron 应用,用户已登录账号 pal_xu),系统性截图它的各个界面,作为 QwenPaw 前端设计对标的参照材料。

## 输出

- 截图存到仓库根的 `.reference-shots/workbuddy/`,命名 `NN-简短说明.png`(两位序号,如 `01-home-office-mode.png`)。
- 同目录写 `capture-log.md`:每张图一条,写清是哪个界面、怎么到达的、值得注意的设计细节(配色、圆角、间距、层级、交互反馈)。如果能从截图判断出主色/背景色的具体色值,一并记录。
- 参照物:`.reference-shots/codex-app/capture-log.md` 是上一轮对 Codex app 的采集日志,格式照它来。

## 铁律(必须遵守)

1. **只浏览,不产生副作用**:绝对不要在输入框发送任何消息、不要创建/删除/修改任何任务、项目、自动化、设置项。会消耗用户额度或改动用户数据的操作一律禁止。打开下拉菜单、切换页面、查看历史任务是安全的。
2. 打不开或找不到的界面,在 capture-log.md 里记一笔"未采到+原因",然后继续下一项。**不要反复重试超过 2 次**,不要陷入验证循环。
3. 如果 WorkBuddy 未运行就启动它(`open /Applications/WorkBuddy.app`),等待加载完成再操作。
4. 采集完不要退出 app,保持原样。

## 采集清单(按优先级)

### P0 主界面与侧栏
1. 首页「日常办公」模式(默认态,含三个模式 tab、快捷能力 chips、输入框)
2. 首页「代码开发」模式(点 tab 切换,仅看布局)
3. 首页「设计创意」模式(同上)
4. 侧栏逐项:助理、项目、专家·技能·连接器、自动化、更多(资料库·灵感)——每个页面一张
5. 侧栏 hover 态一张(鼠标悬停在某个条目上)
6. 侧栏收起/展开(左上角有折叠按钮的话,收起后截一张)

### P0 会话/任务界面
7. 打开一个已有任务(侧栏"任务"列表里的历史任务,如「Word转PDF文件转换」),截会话完整视图
8. 会话中的工具调用/文件产物卡片(如果该任务里有,滚动找到并截图)
9. 会话页的输入框区域特写(底部 composer 及其周边按钮)

### P1 输入框与弹层
10. 首页输入框的「+」菜单展开态
11. 模型选择器(gpt-5.6-sol 下拉)展开态
12. 「选择工作空间」下拉展开态
13. 「默认权限」下拉展开态
14. 「@ 引用对话文件」触发态(在输入框输入 @ 看弹出什么,截完删掉输入的字符)
15. 「/ 调用技能与指令」触发态(同上,输入 / 截完删掉)

### P1 设置与全局
16. 设置界面(通常在左下角头像或菜单里)——主设置页一张,如有多个 tab 每个 tab 一张
17. 深色模式(设置里如有主题切换,切到深色,把首页和会话页各补一张,**截完切回原主题**)
18. 顶部搜索(左上角放大镜)展开态
19. 窗口缩窄到约 900px 宽,看响应式表现,截首页一张(截完恢复窗口大小)

## 操作提示

- 用你的 computer use / 截图工具。macOS 下也可用 `screencapture -l <windowid>` 抓单窗口(windowid 可通过 `osascript` 或 `GetWindowID` 获取),能避免桌面背景入镜更好,不强求。
- 下拉菜单展开时直接截全窗口即可,不用裁剪。
- 每张截图后核对文件确实生成、非全黑/全白,再进行下一张。核对一次即可。

P0 全部采到(或记录了未采到原因),P1 尽力而为。capture-log.md 完整。最后输出一段总结:采到多少张、漏了什么、对 WorkBuddy 设计的三条最突出观察。
