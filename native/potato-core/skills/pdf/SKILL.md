# PDF 阅读与分析

当前原生 PDF 能力是附件文本提取。用户上传 PDF 时，Rust 附件管线提取文本，再将内容交给会话。
基于实际收到的文本总结、检索、比较或回答问题。缺少文件内容时请用户上传 PDF，不要用仅支持 UTF-8 的 read_file 读取二进制 PDF。
保留提取结果中的不确定性；文本顺序不能证明表格布局，不凭空添加页码、图片内容或缺失的文字。

扫描件没有可提取文本时会报需要 OCR，当前未内置 OCR。当前也没有 PDF 生成、合并、拆分、表单填写、加密、页面渲染或 Office 转 PDF 工具。明确说明这些限制，不调用不存在的工具，不声称任务已经完成。
此技能不引入 Python、Node 或 LibreOffice 依赖，也不授予额外权限。
