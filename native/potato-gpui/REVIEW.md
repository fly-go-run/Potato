# GPUI 迁移与视觉检查 · 2026-09-06

用户确定方向：以原 React/Tauri 客户端的精致程度为标准，改用 GPUI Kit / gpui-component，优先布局与样式。
本轮交付可运行的 Rust 原生应用包，并非全量等价验收完成。

## 本轮修复

- 使用原版中性灰配色、系统字体、Lucide 图标；统一侧栏、表单、浮层、边框和阴影。
- 首页输入区、项目/模型/权限原位浮层；导航和列表左对齐。
- 设置页采用统一左右栏，表单输入框 36 px，保存按钮 32 px，字段使用可读下拉选项。
- 修复模型名称挤出“使用”按钮、会话名称挤出菜单按钮的问题。
- 接入跟随系统外观；固定供应商地址只读；隐藏后端尚不支持的 Anthropic 协议。
- 连接测试不再清除未保存状态；保存只确认对应字段提交时的值，保留其他分组及请求期间的新修改。
- 单次任务编辑保留 once 类型，日程修改纳入草稿保护；执行记录读取真实 history 接口。
- 插件列表不再误入技能编辑器；已安装图片插件显示已安装状态。
- 新增会话重命名、置顶、归档/恢复、删除确认。
- 包内应用图标与原版 icon.icns 字节一致；原安装包未被替换。

## 验证证据

- GPUI 客户端：11 项测试通过（含工具 call_id 配对、编辑附件保留、窗口恢复屏幕边界和关闭记忆时忽略旧尺寸）。含真实 SSE 字节边界回放、工具消息去重、PCM 重采样、进程内文档保存与过期冲突、未配置模型失败返回。
- potato-core：21 项单元测试、30 项集成测试通过。使用本机模拟模型、语音、MCP 服务；未调用用户的付费服务。
- macOS ARM64 release 构建成功，ad-hoc 签名通过 `codesign --verify --deep --strict`。
- 签名后的可执行文件约 31.1 MiB，ZIP 约 13.4 MiB。
- Computer Use 实际查看了首页、深浅主题、工作区浮层、任务页与模板编辑/关闭草稿保护、技能/插件、记忆，以及七组设置页面。截图中发现的问题已反馈到上述修复。
- 当前 Computer Use 的 AX 操作有时需后续键盘事件或窗口缩放后才显示最新画面；不能据此宣称所有鼠标、悬停及辅助功能行为均已验收。原位菜单另在不缩放窗口的情况下检查。
- 未在用户数据中创建正式任务、删除会话、导入配置或发送真实模型请求。

## 尚未等价的范围

- 聊天已补编辑重发/取消、末轮重新生成、工具/思考折叠和复制反馈；产物侧栏、数学与多媒体、完整执行轨迹仍需迁移。
- 重发沿用原版同一会话追加消息语义，不截断旧历史；真实模型重发和持续流式输出时的手动滚动仍待验收。
- 会话日期/项目分组、全文搜索结果面板、跨重启草稿、长列表虚拟化仍待补齐。

- 新建单次任务的可视化日期选择、完整调度目标选择、任务编辑器与原版布局仍有差异。
- 设置已补窗口大小记忆与恢复默认大小，窗口位置恢复、语言、自定义主题、上下文用量、设备选择等原版项目。
- 真实账号的模型调用、语音识别、图片生成、IME 完整输入流程、Windows/Linux 实机、发布签名/公证尚未在 GPUI 版本验收。

## 聊天检查补充

使用 `examples/review_fixture.rs` 在 `/private/tmp/gpui-chat-review-data` 写入纯合成会话，通过独立 bundle 和数据目录运行，未修改用户会话。
Computer Use 已验证默认折叠、工具展开后的参数与结果、Markdown 表格、编辑原消息预填、取消编辑恢复原草稿。
工具卡片按 call_id 配对结果，保留孤立输出，支持 plugin/function/MCP 类型；原始存储消息不变。
复制图标有两秒成功反馈；重新生成入口只出现在末轮普通回复，流式输出和编辑期间禁用。

## 滚动、窗口与焦点补充

- 消息区域接入 ScrollHandle：打开会话/发送消息定位到最新内容，向上滚动暂停跟随，提供“回到最新消息”。
- 使用 `review_fixture --long` 创建 40 段合成内容，Computer Use 确认打开后显示最后一段与“长消息结束”。滚轮操作仍被 CUA 的 noWindowsAvailable 阻断，暂停/恢复跟随不能标为实机验收通过。
- 设置、文档和会话管理模态使用 GPUI 的 FocusTrapElement。实测设置首个 Tab 进入弹层；Shift+Tab 循环到末项，Enter 打开添加服务商表单，未触发背景操作。
- 通用设置加入记住窗口大小与恢复默认大小。尺寸保存使用 500 ms 合并，恢复按当前屏幕限制。独立验收目录确认恢复后持久值为 1180×800；未加入位置恢复。
