# 原生回复过程轨迹

按用户选定的过程轨迹方案实现，后续已按反馈移除过程标题和步骤行的悬浮灰底。

- `src/process.rs`：原生时间线、真实步骤状态、单个动态指示、自然高度折叠、详情展示。
- `src/chat.rs` / `src/view.rs`：分组与正式正文衔接、正在阅读时保留展开状态、底部跟随。
- `potato-core/src/protocol.rs` / `tool_execution.rs`：开始时间、单调时钟耗时、并行完成即时通知及历史保存。
- `potato-core/src/model.rs`：思考结束事件、公开阶段消息身份隔离，保留原模型输入与输出顺序。

[设计与原生截图验收](design-qa.md)

## 已验证

- GPUI：64 项测试通过，包含完整选中会话渲染、折叠实测高度与反向续接、减少动态效果、真实滚动位置、手动展开优先级、并行节点保留。
- potato-core 单元：119 项通过，1 项真实模型集成测试保持忽略。
- HTTP/SSE：18 项本地协议回放通过，新增并行完成计时与归档一致性、commentary / final_answer 独立身份测试。
- 原生 debug 构建成功；macOS 实际截图与点击检查覆盖浅色、深色、800px 窄窗口、详情展开、最终回答自动收起、无灰底悬浮。

构建、运行入口及回放方法见设计验收说明。验收窗口使用独立数据目录，不会把演示记录写入用户会话。
