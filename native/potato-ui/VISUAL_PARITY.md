## 本轮首页修正

已安装版本与当前工作区源码有视觉参数差异。本轮按用户认可的截图基准，读取已安装包确认：
标题字号 34 px / 行高 42 px、标题下 margin 64 px，加输入卡外层 top padding 12 px；
首页 bottom padding 16vh，输入卡外层 bottom padding 24 px，卡片圆角 20 px。
当前工作区 `app/` 是另一组 32 px / 28 px / 10vh / 16 px 参数，未修改这些原文件。

已同步画布 #fbfbfb、侧栏 #f0f0ee、输入卡白色、边框 #dcdcd9 和侧栏选中背景。
Iced 单层阴影近似原 CSS 的两层阴影；字体字距仍非像素级一致。
默认演示提示移出常驻底栏，模型位置仍明确显示「本地演示」；错误、连接状态照常显示。
不会为了视觉一致伪造历史会话或真实模型状态。

普通窗口、收起侧栏、全屏截图保存在 `measurements/home-fixed/`。
macOS 全屏快捷键为 Ctrl+Cmd+F，其他平台为 F11；模式随窗口事件同步，避免按尺寸猜测全屏状态。

## 首次测量

2026-09-06，本机 macOS ARM64，release / wgpu，空白首页：

- GPU 版本可执行文件约 9.90 MB（不含后端，不等于最终安装包体积）。
- 一次 `ps` 采样为 RSS 104640 KiB，约 102.2 MiB，CPU 0.0%。
- 没有测量首帧延迟、长会话滚动分位数、流式更新和 GPU 内存。
- 软件渲染早期样本较小，但在 Retina 屏幕上图标坐标/缩放异常；改为默认 GPU 后截图确认修复。

这些是原型观察值，不能用于宣称已经比原版更快。后续必须使用相同会话、窗口尺寸、
屏幕缩放和操作步骤对比，再决定是否值得替代现有前端。

## 2026-09-06 第二轮聊天样式 review

用户指出“复制原文”置顶、底部“3 条消息”等信息与原版不同。本轮重新打开安装版原生窗口，
检查普通回答和工具执行记录，同时核对安装包中的 `MessageActions` 与 `Markdown` 样式。
证据保存在 `measurements/style-review/`，原版截图为当前真实会话，Rust 截图为固定模拟数据。

修正：
- 回答底部使用原版 Lucide Copy 14px 图标，悬停才显示，预留位置避免布局跳动。
- 正常历史加载和完成不展示消息数量、已完成等页脚，恢复操作仅在断流/后台未确认时出现。
- 取消聊天标题额外文本，聊天输入栏不显示首页才有的项目入口，底边距恢复 24px。
- h1/h2/h3 调整至 20/18/16px 半粗；正文行高 28px。
- 行内代码使用浅灰背景和正常文字色；代码块使用 6px 圆角、12px 等宽文字、24px 行高，取消自创标题和边框。
- 工具记录默认折叠，展开再显示参数与输出；不再常驻大卡片和“已完成”标签。

范围限制：工具记录仍未组合为原版的步骤/耗时执行轨迹；重新生成、语法高亮未迁移。
Iced 原生画布还未提供与原版 DOM 等价的无障碍语义；本次截图仅验证可见布局，不代表无障碍或 Windows 验收。
