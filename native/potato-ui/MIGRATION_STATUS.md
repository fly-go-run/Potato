## 日常聊天对齐补充

验收依据为 `app/src/components/chat/MessageList.tsx`、`Markdown.tsx` 和本机已安装 Potato。
原版重新生成仅末轮显示，实际在当前会话重发上一条用户文字；Rust 保持此行为，不创建新分支。
编辑重发复用输入框并保留原消息；取消或发送受理后恢复之前未发送的草稿与附件。
切换/刷新会话、新建会话、切换归档列表保留各自运行期草稿；不会将附件带入另一会话。
发送未被核心受理时保留可重试输入并去掉乐观消息，流式终态后的历史刷新保持跟随底部。

富文本按块解析，表格不再使整段回复退回纯文本；单元格支持强调、行内代码、列对齐与横向滚动。
引用按实际内容高度绘制竖线，代码高亮适配浅色背景，保留原版代码块无额外标题的布局。
附件未选择时不再显示“附件 0”，选择后可逐项移除。用户操作和回答操作均悬停显示。

新增 10 项回归测试覆盖草稿备份、附件隔离、失败重试、流式 Unicode 前缀及整窗富文本布局。
代码高亮依赖已锁定兼容 Rust 1.85 的 plist/time 版本；本轮未在 Rust 1.85 工具链实测。
macOS 实际窗口已验证表格、代码、会话草稿切换、编辑/取消、模拟模型重新生成且保留原草稿。
这是一轮聊天缺口补齐，不等于日常聊天全部对齐；工具轨迹、IME、远程图片/文件预览、复制反馈、
输入框自适应高度、完整无障碍与 Windows 仍在待办中。原版没有现成的消息历史改写入口，
本次“编辑重发”是增补能力，不能称作原地修改历史。

最终 macOS 包已重建并验证 ad-hoc 签名，浅色/深色最终窗口均已复核。


## 聊天审查修复（2026-09-06）

- 升级至 Iced 0.14.0（最低 Rust 1.88），迁移窗口、控件事件、流通道和 Markdown API。text_editor 使用框架的 IME preedit/commit 支持；真实拼音候选与上屏须单独实机验证，粘贴不算 IME 验收。
- 真实核心 function_call/function_call_output 按 call_id 合并，调用显示执行中，输出继承成功/失败状态与原参数；同名不同 ID 不误合并。历史、启动恢复和流式使用相同合并逻辑。
- reasoning 默认折叠成思考过程，不显示正文复制/重新生成按钮。文件附件显示可复制文件名，保留原始附件块供编辑重发；文件预览/下载仍待补齐。
- 流式期间可编辑草稿、切会话、新建；旧流事件按 generation 隔离，后台任务继续执行，返回运行会话可重新连接。发送确认不清空随后输入的新草稿。
- 重新生成发送失败恢复原草稿，不遗留编辑横条。正常发送失败恢复提交内容，并保留发送后输入的文字。
- 跟随滚动使用实际内容高度与底部剩余像素，不再依赖除法比例。HTTP/HTTPS 链接交给系统浏览器，打开失败显示错误。

本次全量 UI 测试 51 项（包括同期设置页测试）、核心 48 项、UI 严格 Clippy 通过；测试网络使用本地模拟服务。
尚未实现追问排队、重启后自动接续、消息文字选择、输入高度/快捷键对齐、多文件/粘贴/拖放附件、工具步骤卡片与按消息稳定 ID 维护展开状态。
正式版等价性、真实服务、Windows 和真实输入法体验仍须分别验收；旧节中的测试数与 1.85 依赖说明为历史记录。
