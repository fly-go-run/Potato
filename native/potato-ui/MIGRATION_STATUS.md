## 本轮完成

新增 `pages.rs` 和 `conversations.rs`，把导航占位替换为实际存储和任务操作。
编辑器保存带预期旧内容，冲突返回错误；删除角色文件同时移除提示文档引用。
异步页面请求按版本隔离，搜索不能使正在执行的会话管理操作丢失完成结果。
偏好每秒合并保存，后台任务完成通知触发会话/消息更新；启动恢复只读取本地数据。
单次提醒按所选 IANA 时区解析普通日期时间，拒绝夏令时不存在/重复时间。

## 验收边界

34 项 UI 测试和 46 项核心测试通过，严格 Clippy 和格式检查通过。
自动化测试使用临时数据库和模拟网络服务，不读取家庭账号。
macOS 窗口已验证记忆保存回读、技能创建、提醒手动执行和聊天自动刷新，以及置顶后保留消息。
真实豆包/sub2api、Windows、正式安装升级仍未验收，不能称为与旧版完全等价。
定时依赖应用保持运行；偏好仍可能在修改后立即强退时丢失最后一秒。
会话搜索当前扫描消息正文，尚不适合极大历史库。完整差距以本表跟踪。

优先继续按原版补齐聊天工具轨迹/回合归组、附件与链接预览、IME 与输入快捷键，再补完整设置和项目操作，最后做 Windows 和真实家庭使用验收。


## 日常聊天对齐补充

验收依据为 `app/src/components/chat/MessageList.tsx`、`Markdown.tsx` 和本机已安装 Potato。
原版重新生成仅末轮显示，实际在当前会话重发上一条用户文字；Rust 保持此行为，不创建新分支。
编辑重发复用输入框并保留原消息；取消或发送受理后恢复之前未发送的草稿与附件。
切换/刷新会话、新建会话、切换归档列表保留各自运行期草稿；不会将附件带入另一会话。
发送未被核心受理时保留可重试输入并去掉乐观消息，流式终态后的历史刷新保持跟随底部。

富文本按块解析，表格不再使整段回复退回纯文本；单元格支持强调、行内代码、列对齐与横向滚动。
引用按实际内容高度绘制竖线，代码高亮适配浅色背景，保留原版代码块无额外标题的布局。
附件未选择时不再显示“附件 0”，选择后可逐项移除。用户操作和回答操作均悬停显示。

新增 10 项回归测试覆盖草稿备份、附件隔离、失败重试、流式 Unicode 前缀及整窗富文本布局。
代码高亮依赖已锁定兼容 Rust 1.85 的 plist/time 版本；本轮未在 Rust 1.85 工具链实测。
macOS 实际窗口已验证表格、代码、会话草稿切换、编辑/取消、模拟模型重新生成且保留原草稿。
这是一轮聊天缺口补齐，不等于日常聊天全部对齐；工具轨迹、IME、远程图片/文件预览、复制反馈、
输入框自适应高度、完整无障碍与 Windows 仍在待办中。原版没有现成的消息历史改写入口，
本次“编辑重发”是增补能力，不能称作原地修改历史。

最终 macOS 包已重建并验证 ad-hoc 签名，浅色/深色最终窗口均已复核。
