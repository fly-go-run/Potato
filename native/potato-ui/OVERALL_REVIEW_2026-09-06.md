# Rust 原生版整体检查（2026-09-06）

结论：仍是开发预览，不能作为原版完全等价替代。下方首次检查保留为历史基线；本日后续已补 macOS 辅助功能桥接及第一批功能缺口，最新状态见“按报告逐项修复”。纯坐标点击仍报错，但 AX 按钮点击和输入字段设值已经可用。

## 证据与边界

- 原版：本机 `/Applications/Potato.app`，关于页显示 2.0.6。实际查看首页、设置全部六个分类、服务商详情、定时、技能、记忆；没有修改账号或提交任务。
- 原生版：本仓库 `native/potato-ui`，Iced 0.14 + 进程内 `potato-core`。实际启动首页、通过键盘打开设置。后续修复后的键盘复查结果见本文末尾。
- 原生窗口 AX 只有窗口、红绿灯和菜单，不含页面按钮、字段、列表；不能用 AX 点击页面控件。
- CUA 坐标点击连续返回 `Computer Use server error -10005: noWindowsAvailable`。前置窗口、快捷键激活和重置 CUA 会话后仍失败。不是应用按钮已经点击但业务失败，而是工具未能派发鼠标操作。
- 原版 AX 点击大多数导航正常，但部分截图滞后、空白，附件菜单 AX 点击未能验证展开。空白及状态不符截图没有计入有效证据。两个窗口尺寸不同，不做像素级等价结论。
- 截图存于 `measurements/overall-0906/`。本轮实际窗口证据与代码检查分开标记；自动化回归不代替真实鼠标、IME、联网服务或 Windows 验收。

## 本轮修复与回归

1. `package.py` 携带原版 Tauri `.icns` 并设置名称与图标字段；签名后执行严格校验，生成平台 ZIP。窗口使用同源 PNG，标题统一为 Potato Native。
2. ⌘N/⌘K/⌘B/⌘/（其他平台 Ctrl）接到现有操作；⌘N 聚焦输入框，⌘K 展开并聚焦搜索。设置模态打开期间底层聊天命令仍隔离。
3. 关闭会话搜索时清除过滤，避免列表悄悄缺项。
4. 输入区权限按钮连接实际安全设置；打开指定设置分类仍保护未保存内容。
5. 新增导航草稿/模态隔离及指定设置入口回归。UI 58 项、核心 48 项共 106 项测试通过，UI 严格 Clippy 通过。首次沙箱运行的流测试因不能绑定回环端口失败，允许本地测试端口后全量通过。

优先处理：恢复 CUA 鼠标操作并补齐原生 AX/键盘可达性；逐项完成服务商、通用、安全与输入菜单；再对齐定时/技能/记忆布局与功能。不能把本次记录写成“所有按钮均已检查通过”。
