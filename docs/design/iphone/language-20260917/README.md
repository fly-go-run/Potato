# iPhone 界面语言

2026-09-17。仅覆盖原生 iPhone 客户端。已发布至 TestFlight 0.2.2（2026091701），既有个人内测组 Testing；见 [发布记录](release-2026091701/README.md)。

设置页新增语言选择：

- 跟随系统（默认）：按系统首选语言列表匹配中文或英文；没有匹配时回退英文。
- English。
- 简体中文。

选择后即时预览，点击保存持久化到现有本地设置；取消或滑动关闭恢复原语言。首次升级无需迁移，旧设置未包含语言字段时默认跟随系统。跟随系统模式会在返回前台和系统区域通知时刷新。

聊天、设置、资料库、远程会话、排队消息、模型选择、语音提示、无障碍标签与本地错误提示接入中英文资源。对话正文、已有标题、输入草稿、用户回复偏好和模型指令不随界面语言重写；服务端原始消息保留原内容。系统权限对话框由 iOS 决定语言，麦克风用途说明提供中英文资源。

实现：`Sources/AppLanguage.swift` 管理语言解析、可观察的界面更新和本地化插值。`Sources/Localization/{en,zh-Hans}.lproj/Localizable.strings` 保存界面翻译，新增文案使用 `L10n.tr("文案")` 或包含插值的同类调用。插值数据与查找键分离，不翻译用户内容，也不将内容作为格式化指令执行。

工作区使用 `StateObject` 的延迟初始化，避免语言刷新时重新加载、重置草稿或写入工作区。切换语言不使用 `.id()` 重建会话视图。

验证记录：完整 iPhone 单元测试 185 项通过；随后修正语言预览触发工作区初始化的问题，专门验证预览、保存、取消、重启、跟随中英文系统以及未发送草稿保留。最终复测 5 项语言单元测试和 1 项完整 UI 流程全部通过（0 跳过、0 失败）。
