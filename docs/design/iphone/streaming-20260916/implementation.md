# iPhone 流式输出优化

2026-09-16。在 0.2.2 (2026091606) 源码基础上实现，已发布 iOS 0.2.2 (2026091607)，配套 Worker 已上线。保留此前设置下拉关闭、亮色/暗色/自动等改动。

## 改动

- 云端持久化任务增加 `/events?after=` SSE 订阅。先补读游标之后的数据，然后在事件落盘后唤醒读取者。生成依然由 alarm 持有，客户端断线不影响生成。快速事件合并窗口 40 ms；每页最多 64 个事件，保留原体积限制。按 pull/backpressure 取页，15 秒心跳、60 秒连接轮换，最多 8 个订阅者。
- iOS 优先持续订阅；旧接口 400/404/405/501 或非 SSE 响应回退原分页。网络错误自动按内存游标重连；终态必须等消费到 last 才生效。原 PUT 幂等提交、POST 停止、工具事件和部分结果保留逻辑继续复用。
- 显示缓冲独立于实际文字及游标：首字符收到即显示，32 ms 定时步进，积压追赶目标为最后一批到达后的 240 ms（调度正常时）。按 Swift Character 切片，中文、组合字符、家庭 emoji 不被拆开。替换版本、完成/停止、后台和减少动态效果直接显示真实全文。滚动追底跟随可见文字变化，用户上滑仍暂停追底。
- 持久化与显示步进分离：SSE 页大约每 250 ms 才强制保存，安静期使用原 250 ms 延迟保存；终态立即保存。一次快照始终包含匹配的正文、工具产物与游标。突然退出最多回到旧检查点，通过服务端补读恢复；不保存独立的“显示游标”。
- Markdown 缓存当前全文的块解析结果；正文没变时不重复解析，并复用未变化段落的 AttributedString。文本改变仍解析块结构，稳定段落的行内格式缓存被保留，旧尾段缓存删除。未宣称实现完整增量 Markdown parser。
