# Grok参考输入面板与长文编辑

2026-09-12。用户选定自己的Grok截图作为原生iPhone输入面板目标，随后要求像素级借鉴并移除多余的键盘按钮。这份规格取代前一轮语音稿中的独立“修改”按钮、24pt正文和较高的录音面板。

## 视觉目标

参考为 [用户截图](grok-reference.jpg)，589×1280px。以输入面板为比较范围，按相同逻辑屏宽等比比较；不复制Grok品牌、消息页或截图中的第三方键盘。键盘仍由iOS和用户选择的输入法提供。截图不足以确认Grok实际内部实现或勾号语义。

- 浅灰白面板，约26pt圆角，左右10pt边距，移除语音状态的实线边框。
- 黑色文字在上，内容自然增高；下面一行是取消、细波形、黑色确认圆按钮。圆形视觉直径33pt，触摸区域仍44pt。正文采用系统Body字号并支持动态字号；按用户最新反馈，以黑色突出文字，不照搬参考图灰字。
- 删除独立键盘按钮及常驻上下堆叠计时。语音时点击正文，结束采集并等待最终转写后进入键盘编辑；VoiceOver有操作提示。
- 中间区域左滑超过70pt取消，上滑超过60pt发送，方向占优才触发。正文滚动不触发这些手势。
- 根据既定“直接发送”方向，勾号在Potato中明确执行“结束录音并发送”，无额外确认步骤；上滑也执行相同操作。空转写或连接中不能发送，收尾时有进度反馈。取消可撤回尚未提交的录音，恢复进入前的草稿和附件。

## 长文本与状态

文字和语音共用原生UITextView的实际排版高度。文字默认最大180pt，语音220pt，再按键盘后的可用空间、附件和操作区收紧；SE和大字模式不会硬塞固定行数。达到上限内部滚动，不截断500／1000字，也不自动变成附件。

溢出后出现“展开”；原生全屏编辑器使用同一份草稿和UTF-16选区，支持直接发送、收起继续输入。语音展开会先收齐final，旧录音回调不能覆盖新编辑。删除文字会缩回输入高度。中文组合输入期间不反复重写UITextView.text。

语音默认跟随新增片段；拖动正文暂停跟随，显式“回到最新”恢复。插入位置可能在已有文本中间，因此跟随插入点，不一律滚到全文末尾。展开、取消、发送、重启都沿用原有会话草稿及附件存储。

## 音量波形

真实录音直接从本地16-bit PCM计算RMS音量，音频采样后即更新，不等待WebSocket上传或豆包转写。21个近期音量点驱动柱高；停止说话后零音量逐步替换旧点，归于点线，没有正弦、取模或循环节奏。减少动态效果时保留静态指示。

DEBUG预览去掉原先`length % 7`的周期图形，使用3.6秒合成中文验证音频的音量包络，随后静音。预览仍是测试场景；真机麦克风、环境噪音及蓝牙响应需要实机验收。
