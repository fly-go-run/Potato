# iOS 远程审批弹窗

2026-09-13，工作树实现，未分发。

自动审批仍产生手动审批的原因：`potato-core/src/approval.rs` 中模型返回 `AskUser` 或审查失败时，保留待审批请求，并携带 `review_rationale` / `review_failure`。远程快照已透传这些字段；本次让 iOS 解码并展示原因，没有改变桌面审批政策。

交互：进入远程会话或轮询发现新的审批，自动展示原生底部面板。显示电脑、会话、审查原因、操作说明、命令、目录、沙箱外执行提示，完整参数可展开和选择复制。允许仅作用于当前 request_id；拒绝明确标为破坏性按钮。底部操作区固定，正文可滚动。

“稍后处理”及下滑只收起面板，消息列表保留入口，同一请求不重复自动弹出；新请求依次提示。其他面板、录音或提交期间暂缓自动展示。提交时禁用按钮和手势关闭；失败保留错误并刷新状态。失联或后台禁用决策；电脑端处理或过期后显示不可用状态。已成功响应的请求在本地排除，防止旧轮询结果重新显示。

修改限于 SwiftUI 原生 iOS 的远程界面、解码和针对性测试，沿用现有远程 RPC。未改动旧桌面实现。

验证：iPhone 17 模拟器 Debug 构建成功；RemotePresentationTests 8 项通过（包括旧桌面字段兼容和模型审查原因）；RemoteProcessUITests 3 项通过，覆盖允许、拒绝、收起重开、断线禁用、大字号过期状态，并回归后续提问/停止/失败。使用 loopback 合成 RPC，不执行真实命令。截图已人工查看：[审批面板](approval-sheet.png)、[最大辅助字号下的过期状态](approval-expired-large.png)。正文可滚动，底部操作固定。

本机结果包：`/tmp/potato-approval-tests.xcresult`（8 项单测通过，首轮 UI 因测试环境变量未传入而跳过）；`/tmp/potato-approval-ui.xcresult`（正确传入 TEST_RUNNER_POTATO_IOS_PROCESS_UI=1 后，3 项 UI 全部执行通过）。未做真机联调或 TestFlight 发布；未验证本轮未改动的桌面自动审查模型实际调用。

## 紧凑面板与持续目录授权

后续按反馈改为默认 520pt 面板，底部横排拒绝/允许，展开详情自动升为大面板；辅助字号使用大面板并保留滚动。

支持目录授权时增加“仅这一次 / 本会话允许目录 / 始终允许此目录”选择，后两项显示确切目录、是否递归及有效期。仅授权读取/列举/搜索；复用核心的目录授权校验和持久化逻辑，不提供任意命令永久放行。远程 RPC 新增范围传输，目录路径和递归范围取桌面待审批记录，手机不能任意扩大目录。桌面快照声明 `approval_scope_protocol: 1` 后才展示持续授权选项；新旧客户端仍默认单次审批，需要同步更新桌面端才能启用。

验证：iOS 构建成功；3 项模拟器 UI 回归通过，包括持续目录选择并提交，合成服务请求日志已核对 `persistent_directory`；Rust 12 项 remote_tests 通过，新增测试验证目录范围、会话/永久有效期、忽略手机伪造的扩大目录参数、禁止为不支持的操作持续授权。本轮没有真机联调及发布。

## 去冗余精简

按用户确认移除电脑/会话副标题及本次/本会话重复提示；合并目录名与完整路径，末级目录加重。权限缩为“只读 · 含子目录”（非递归明确“不含子目录”），完整操作定义移入详情。主按钮统一“允许”，始终允许时保留跨会话生效和撤销说明。默认高度470→360pt，详情展开与辅助字号仍使用大面板。

构建与3条UI回归通过，覆盖收起/拒绝、持续目录授权、辅助字号断线/过期；新增断言检查重复说明消失及持续说明保留。结果：`/tmp/potato-approval-trim.xcresult`。[精简截图](trimmed-implementation.png)、[持续授权截图](trimmed-persistent.png)已目视检查，无文字遮挡。未发布。
