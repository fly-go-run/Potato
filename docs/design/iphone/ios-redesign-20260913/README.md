## 当前产品证据

以下保存第一轮在 iPhone 17 / iOS 26.3 模拟器启动 `com.potato.iphone.prototype --ui-testing --reset --remote-preview` 的改造前证据，使用独立测试沙盒与合成设备列表，未向真实电脑发送任务。第一轮当时尚未重新构建；后续修复均另行编译和验证，见上面的修复记录。

1. **远程首页：信息层级偏重。** 同屏常驻设备筛选、置顶、项目、会话、底部搜索和两个创建入口。项目与设备应该可达，但无需每次开始聊天都浏览完整目录。截图 01。
2. **侧栏：点击有效，滑动无效。** 点击打开侧栏正常；在已打开侧栏的空白区域从右向左拖动，侧栏仍停留原位。另一条从远程主页左侧向右拖动的人工模拟动作进入了项目行，说明该输入未实现预期的抽屉操作；还需 XCTest 控制触点与时长，区分手势冲突和模拟器鼠标动作。`WorkspaceView` 仅用 `sidebarVisible` 点击切换和固定 offset，没有抽屉 DragGesture。截图 02。
3. **空白新对话：视觉元素过多。** 大星形、大标题、两行说明、三张建议卡占据主要内容区；底部输入反而较弱。导航与输入区都显示本地体验。截图 03。
4. **模型与思考设置：功能缺口，源码确认。** 本机 `ConnectionSettings` 仅有 model 字符串，设置页没有思考设置；`ChatService` SSE 仅处理 content/search/length/done，未接收 reasoning_content。本机实际思考内容因此无法展示。远程 `RemoteTaskView` 无模型/思考入口，`RemotePendingSend` 仅携带文本、会话、项目；Rust `remote_mutation` 未传递模型与思考覆盖。不能仅画一个选择器就声称已生效。
5. **过程反馈：源码确认，动态验收待补。** 远程已有稳定 ID 分组、默认折叠、进行中的 ProgressView，但还同时显示顶部“正在执行”和底部通用处理中提示。每两秒拉取快照；尚无本轮动态服务证据证明真机动画、流式节奏或恢复行为。普通聊天在首个正文出现前仅显示“正在准备回复”。

## Potato 设计原则（设计推导，非竞品事实）

- 首页服务“立刻发起或继续一件事”。默认空白对话不放示例文稿和三张功能宣传卡。示例文稿留在资料库/更多中。
- 一个稳定的侧栏承担历史、项目、远程设备与设置。远程列表仍可浏览和搜索，但不强迫用户每次输入都先选目录。设备未关联时显示清楚的连接入口。
- 显示目标：本机对话或具体电脑。首次选择、离线和切换目标时都有明确反馈。不要把远程执行与手机模型聊天混成无提示的自动切换。
- 模型与思考靠近输入区；点击打开一张原生底部面板。模型显示名称、来源和当前值；思考强度只提供服务声明支持的选项。未声明能力时使用服务默认并解释，不能按模型名称臆造高/中/低。
- 远程默认跟随电脑。每次覆盖必须进入不可变发送负载，重试保留同一模型/思考选择，不能偷偷改全局桌面设置。运行中的追问要说明沿用当前任务配置或仅对下一轮生效。
- 保留现有暖白、深灰、系统字体与土豆标识；触点至少 44pt，中文排版以正文可读和留白为主。

## 手势与动态规则草案

侧栏：根页面水平右拖打开、左拖关闭，内容跟手；小幅拖动回弹，足够距离或速度完成。优先判定水平方向，垂直滚动不打开侧栏；输入编辑、语音取消、代码/表格横向滚动不能被抢走。在有返回栈的远程子页优先保留原生返回手势。键盘收起且草稿保留；VoiceOver 保留明确按钮和关闭动作。Reduce Motion 使用静态/短淡变，不强制大范围移动。

生成：等待响应 → 思考 → 工具执行/等待审批 → 回复 → 完成/停止/失败，按真实协议状态切换。只显示一个主要的当前状态。思考行可展开摘要/服务公开内容，有轻微明暗变化或点状活动指示；完成即停止循环，保留“已思考”与真实时间。没有收到思考内容时不生成假思考文本或假倒计时。后台、取消、断连后正确终止或显示未知/重新连接状态；离开远程页不声称电脑已停止。

正文追加时尽快显示，避免逐字假打字延缓真实输出；手动回看停止追底，用户主动回到最新后恢复。展开过程或工具详情不应无条件把阅读位置拉到底。
