# iOS 回复操作栏精简

2026-09-13。范围：`native/potato-ios` SwiftUI 本机聊天。按用户确认采用「复制、重试、…」，不修改 GPUI、远程任务执行或 Worker。

## 交互

- 复制使用 `square.on.square`，成功后原位显示对勾，两秒后恢复。
- 回复操作栏图标 18pt，点击区域 44×44pt，常驻朗读移入更多面板。
- 最后一条回复的更多面板首项为「换模型重新回答」，并显示该回复当前版本的模型和思考设置。下方依次为分享、朗读/停止、选择文字、存为工作文稿。较早回复保持复制与更多，不新增历史重试语义。
- 直接重试沿用当前显示版本的模型与思考设置；缺少模型信息的旧记录使用会话选择。服务已变更或配置失效时提示错误，保留原回复。
- 换模型面板使用临时选择；点“重新回答”才请求。取消不保存选择，确认也不改变输入框模型、未发送文字或附件。重试目标绑定消息 ID，过期面板不能重试其他回复。
- 新回复保留旧版本，仍可前后切换。生成中隐藏当前操作栏，禁止重复提交。
- 更多面板使用白色列表行和紧凑分组间距；大字号展开为可滚动整页，装饰图标固定尺寸，避免挤占文字。

## 验证

- iPhone 17 / iOS 26.3：104 项原生单元测试通过。
- 7 条模型与回复界面回归通过，覆盖复制反馈、更多面板、选择文字、取消换模型保留草稿和会话配置、直接重试、换模型重新回答、旧版本切换、模型选择持久化、服务切换以及最大辅助功能字号。
- 截图验收后调整面板底部空间与大字号图标；普通字号及最大字号针对性复验记录见 `/tmp/potato-reply-verified-20260913.xcresult`。
- 测试使用 URLProtocol 离线合成模型回复，截图中的 MODEL/THINKING/EFFORT 为请求参数回显。没有真实模型费用，也未上传或发布 TestFlight。
- macOS 窗口控制接口持续超时，未能把模拟器窗口打开供人工操作；通过 Xcode 运行模拟器测试并导出原生截图。真机触感、完整 VoiceOver 人工验收未覆盖。
