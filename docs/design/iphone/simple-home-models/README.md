# 简洁首页与模型选择

2026-09-13，依据用户提供的两张手机参考图，调整现有 SwiftUI 客户端。桌面 GPUI 与 Rust 核心不在本轮改动范围。

## 设计

首页移除引导卡片和说明段落，仅保留居中的 Potato 标记和「今天，想聊什么？」。底部输入框继续支持附件、原位语音、展开编辑及发送，模型名与思考状态以单行胶囊显示。键盘出现时欢迎区跟随剩余高度居中。

沿用 Potato 的浅色画布（约 `#F8F7F4`）、白色输入框、深色正文（约 `#1F1F1D`）、灰色次要信息（约 `#757570`）与轻描边。欢迎语使用系统圆体 22pt，其余使用系统动态字体；输入框圆角 28pt、左右边距 10pt。保留现有 PotatoMark 资源，不复刻参考产品品牌图形。

本机和远程共用原生底部弹层：

- 第一层「选择模型」：最多四个常用入口，当前选择始终可见；独立一行「思考」与「更多模型」。远程保留「跟随电脑」。
- 「思考」：展示服务实际声明的档位与默认选项。更改立即保存，可返回模型列表或完成。
- 「更多模型」：搜索完整目录；本机额外保留手动模型与连接设置，远程可刷新电脑目录。
- 再次选择当前模型保留思考配置；切换其他模型沿用既有校验和默认逻辑。列表搜索不影响返回后的常用模型。
- 普通字体根据模型数量使用不超过 530pt 的底部弹层，可拉大；无障碍大字和二级设置展开到大尺寸并可滚动。
