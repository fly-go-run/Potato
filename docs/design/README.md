# Potato 界面原则

> 当前实现范围为 Rust GPUI + potato-core。涉及旧 Web/Tauri 技术路线的段落仅作历史参考，以[原生架构与退役原则](../architecture/native-only.md)为准。

更新：2026-09-05。依据本轮用户的明确反馈制定。

旧版 `app/docs/` 里的产品模仿要求、阶段性视觉方案、设计变量的专属修改者限制，均作为历史记录，不再约束新设计。不批量删除旧审查材料，以保留问题与决策的来历。

## 当前方向

- 简洁，接近 macOS / iOS 的信息组织与控件秩序；不复刻任何一个 AI 客户端。
- 用排版、对齐、留白和清楚的状态表达质感，不增加营销装饰。
- 首页只有问候与输入区。不常驻快捷键教学、辅助口号或解释性小字。
- 设置优先使用明确的项目名。说明只用于权限含义、异常、不可用原因或必须解释的操作；技术诊断按需展开。
- 一级内容、二级导航、表单、弹层使用一致的语义颜色与圆角。强调色只用于交互与状态，不给每块内容涂颜色。
- 设置面板的标题和导航固定，内容单层滚动；切换分区回到顶部。长说明不挤走对应控件。
- 会话有轻量标题；正文和输入区共享阅读宽度。时间等次要信息按需出现，不占用标题的常驻空间。
- 错误必须可见。功能失败不能只在控制台或 catch 内消失。

## 本轮视觉基础

字体沿用系统字体：macOS 使用 SF / 苹方；正文 14–16px，设置标题 22px，首页问候 28–32px。控件圆角 8px，分组 12px，输入框及弹层 16px。

浅色：白色画布、`#f5f5f5` 侧栏、`#1d1d1f` 主文字，中性灰选中态与黑色主按钮。深色：`#181818` 画布、`#202020` 侧栏、近白文字。默认不使用绿色强调色；仅错误、警告等语义状态保留提示色。主题支持浅色、深色、跟随系统与导入自定义主题。

macOS 优先使用 `-apple-system` / `BlinkMacSystemFont` 和苹方；恢复系统默认字体平滑，不强制灰度平滑。正文 16px、导航 15px、会话标题和工具动作 14px；通过字号和字重表达层级，避免大面积浅灰小字。

布局：`侧栏 | 对话标题 + 阅读区 + 输入框`；设置为 `分区导航 | 标题 + 分组表单`。

macOS 原生材质、窗口缩放与系统控件的行为应在 Tauri 实机验证，不能以浏览器截图代替。无需为视觉质感先重写成原生应用。
